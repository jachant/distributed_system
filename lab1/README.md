# lab1_pthreads.pdf

Работа состоит из трёх заданий, каждое в своей папке:

| Папка | Задание |
|---|---|
| `task1/` | Параллельный поиск заданного количества точек множества Мандельброта |
| `task2/` | Задача N тел (метод Эйлера, с учётом третьего закона Ньютона) |
| `task3/` | Своя блокировка чтения-записи (`rwlock`) на односвязном списке, сравнение с `pthread_rwlock_t` |

В каждой папке есть исходный код (`src/`, `include/`), тесты (`tests/`) и `Makefile`.

## Сборка и запуск

Интерфейс `make` во всех трёх заданиях одинаковый. Команды выполняются внутри папки задания (`cd task1`, `cd task2` или `cd task3`):

| Команда | Что делает |
|---|---|
| `make` | собрать программу `./program` |
| `make run` | собрать и запустить на примере |
| `make test` | собрать и запустить тесты |
| `make bench` | быстрый замер времени на 1, 2, 4, 8 потоках |
| `make clean` | удалить всё собранное |

Дополнительно: в `task1` есть `make check` (запуск и проверка полученного CSV на Python, рисует `mandelbrot.png`), в `task2` есть `make plot` (запуск и картинка траекторий `trajectories.png`).

Отличаются только аргументы самой программы.

**Задание 1:**
```
./task1 <nthreads> <npoints>
```
Пример: `./task1 4 100000`. Результат — файл `mandelbrot.csv` с координатами найденных точек.

**Задание 2:**
```
./task2 <tend> <input_file> [nthreads] [dt]
```
Пример: `./task2 63115200 data/inner_planets.txt 4 1800` (Солнце и 4 планеты, 2 года, шаг 30 минут). Число потоков и шаг можно не указывать: по умолчанию 1 поток и `tend / 1000`. Входной файл: первая строка — число тел `n`, затем `n` строк по 7 чисел `m x y z vx vy vz`. Результат — файл `trajectories.csv`, в каждой строке `t, x1, y1, ..., xn, yn`.

**Задание 3:**
```
./task3 <nthreads> <lib|my>
```
`lib` — библиотечная `pthread_rwlock_t`, `my` — своя. Как в исходном `pth_ll_rwl.c`, остальные параметры читаются со стандартного ввода: число ключей в начальном списке, число операций, доля поисков, доля вставок. Пример:
```
echo "1000 100000 0.8 0.1" | ./task3 4 my
```

## Методика замеров

- Каждая конфигурация запускалась **5 раз**, в результат берётся **минимальное** время.
- Число потоков: 1, 2, 4, 6, 8, 10, 12, 16.
